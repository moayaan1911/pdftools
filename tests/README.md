# Tests

E2E + debug scripts for the PDF toolkit. All scripts use Playwright (Chromium, headless) against a running dev server.

## Layout

```
tests/
├── scripts/         # E2E test runners (one per tool)
└── debug/           # One-off probes used during diagnosis
```

## Setup

```bash
npm i -D playwright
npx playwright install chromium
```

Dev server must be running on port 4173:

```bash
PORT=4173 npm run dev
```

## Run a single test

```bash
node tests/scripts/e2e-<tool>.mjs
```

Each script prints a per-viewport (desktop 1280×800, mobile 390×844) result + a final summary. Exits 0 on pass, 1 on fail.

## Test files (E2E)

| Script | Tool | What it checks |
| --- | --- | --- |
| `e2e-merge.mjs` | Merge PDFs | Upload 2, merge, verify page count + download |
| `e2e-split.mjs` | Split PDF | Both modes (by range, every page), zip contents |
| `e2e-rotate.mjs` | Rotate Pages | Thumbnails render, rotate-right applies 90° to output |
| `e2e-reorder.mjs` | Reorder Pages | Remove page via ✕, apply, verify page count drops |
| `e2e-pdf-to-images.mjs` | PDF → Images | PNG + JPEG zip, magic-byte check on each blob |
| `e2e-images-to-pdf.mjs` | Images → PDF | Upload 2 PNGs, button label shows "2 pages", output has 2 pages |
| `e2e-extract-text.mjs` | Extract Text | Per-page tabs render, download `.txt` with 3 page markers |
| `e2e-html-to-pdf.mjs` | HTML → PDF | Default template + uploaded `public/sample.html` |
| `e2e-page-numbers.mjs` | Page Numbers | All 6 positions × 4 formats tested, output valid |
| `e2e-watermark.mjs` | Watermark | Text watermark, scope = all/odd/even |
| `e2e-metadata.mjs` | Edit Metadata | All 5 fields read back correctly from output |
| `e2e-forms.mjs` | Fill Forms | Uses `make-form-pdf.mjs` output, fills 4 field types |
| `e2e-crop.mjs` | Crop Pages | Custom 20pt + 16:9 preset, MediaBox verified |
| `e2e-extract-pages.mjs` | Extract Pages | Range input + click-to-select, output page count |
| `e2e-batch.mjs` | Batch Process | Zip of N rotated PDFs, all rotations = 90° |
| `e2e-viewer.mjs` | PDF Viewer | Canvas renders, page nav, zoom |
| `e2e-compare.mjs` | Compare PDFs | Both canvases render, sync nav, labels correct |

## Fixtures

`public/` holds test PDFs used by the scripts:
- `tds_zebpay1.pdf`, `tds_zebpay2.pdf`  -  original 3-page fixtures
- `form-sample.pdf`  -  generated by `make-form-pdf.mjs` for the forms test
- `test1.png`, `test2.png`  -  generated for the images-to-pdf test
- `sample.html`  -  sample HTML for the html-to-pdf upload test
